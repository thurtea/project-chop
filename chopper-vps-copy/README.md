# Chopper website

The site for Chopper, a co-op survival game in Unity, at https://thurtea.com/chopper/.

Plain HTML, CSS, and one PHP form. No build step.

## Files

| Path | What it is |
|---|---|
| `index.html` | The game |
| `gallery.html` | Screenshots and art |
| `demo.html`, `demo.php` | Demo requests. Saved to `private_html/chopper-demo-requests.jsonl` and mailed to itsthurtea@gmail.com |
| `main.css`, `main.js` | Styles, and the demo confirmation |
| `favicon_io-chopper/` | Favicons |

GitHub: https://github.com/thurtea/project-chop
