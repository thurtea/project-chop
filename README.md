# 3D-Game

Private workspace for game projects made with Unity.

| Folder | What it is |
|---|---|
| `Chopper/` | Chopper, a co-op survival game (Unity 6000.5.10f1, URP, FishNet). Start with `Chopper/summary.md` and `Chopper/RUNNING.md`. |
| `Setup Guide In-Editor Tutorial/` | Unity's in-editor tutorial project. |

Website: `Chopper/Website`, published with GitHub Pages by `.github/workflows/chopper-pages.yml` (run by hand from the Actions tab). 

Builds: `.github/workflows/chopper-release.yml` or locally (see `Chopper/RUNNING.md`). Repository setup notes: `Chopper/Docs/REPO_MOVE.md`. 

Reference images (menu examples, concept art): `Chopper/Docs/references`.
