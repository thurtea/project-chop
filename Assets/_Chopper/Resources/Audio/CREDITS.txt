Audio in this folder is loaded by name at runtime (Resources.Load("Audio/<name>")). A name with -1, -2 and so on
has variations picked at random. Any clip dropped here with the same name replaces the sound without code changes.

Every effect was polished for Chopper: low rumble removed, silence trimmed, short fades, each family brought to one
loudness with a soft peak ceiling, saved as 16-bit 44.1 kHz mono WAV. There is no background ambience on purpose.
