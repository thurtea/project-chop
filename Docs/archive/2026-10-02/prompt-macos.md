Copy everything below the line into a new Claude Code or Copilot session started on your Mac.

Before you do that, know this: you probably do NOT need to build anything on the Mac. The Windows machine already builds the macOS version (`Chopper-0.1.0-macos.zip`, universal for Intel and Apple Silicon). Copy that zip to the Mac and run it (section A). Only continue to section B if the zip does not work and the Mac has to produce its own build.

I want you to test the macOS version of Chopper, a co-op survival game made in Unity. Act without asking me to do things for you, except steps that need a graphical sign-in (say so clearly and stop instead of retrying in a loop). Style rule: no emojis and no em dashes anywhere.

## A. Test a prebuilt zip (do this first)

1. I will put `Chopper-0.1.0-macos.zip` somewhere (ask me for the path if you cannot find it). Unzip it into `~/chopper-test`.
2. The app is not signed. Remove the quarantine flag and start it headless to see whether it loads: `xattr -dr com.apple.quarantine ~/chopper-test/Chopper/Chopper.app` then `~/chopper-test/Chopper/Chopper.app/Contents/MacOS/Chopper -batchmode -nographics -chopperHost -chopperStopAfter 15 -logFile ~/chopper-test/run.log`. The log must contain "Scene loaded: World" and no "Crash!!!". Then open it normally (`open ~/chopper-test/Chopper/Chopper.app`; if Gatekeeper still blocks it, tell me to right click the app and choose Open) and report frame rate, anything pink, black or missing, audio, mouse look, fullscreen and a controller. Stop here if it works.

Do not retry it. Ask me to open Unity Hub, click Sign in, finish the browser login, then Licenses, Add, "Get a free Personal license". When I say that is done, install the editor from the Hub window (Installs, Install Editor, choose 6000.5.10f1, tick Mac Build Support) or try the standalone CLI bundled in the app: `"/Applications/Unity Hub.app/Contents/Resources/unity" install 6000.5.10f1` and `... install-modules -e 6000.5.10f1 -m mac-mono --accept-eula -y`. Pick the Apple Silicon editor on an arm64 Mac.
- Without an activated license, Unity batch mode exits with code 198 and "No valid Unity Editor license found". Stop and wait for me if you see that.

Where `<UNITY>` is `/Applications/Unity/Hub/Editor/6000.5.10f1/Unity.app/Contents/MacOS/Unity`. The project: https://github.com/thurtea/Chopper.git (branch main), already cloned in `~/projects/Chopper` (pull first). The first import takes several minutes.
